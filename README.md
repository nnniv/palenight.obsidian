## Installation

1. Open Obsidian **Settings → Appearance**
2. Under **Themes**, click **Manage**
3. Search for "Palenight" and click **Install** (or copy the `Palenight` folder to `.obsidian/themes/`)
4. Select **Palenight** from the Theme dropdown
